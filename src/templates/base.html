Instrucciones de Uso

Siga estos pasos para utilizar el clasificador de ECG:

  1. Seleccione un archivo de ECG en formato .csv.
  2. El archivo debe contener las derivaciones del ECG necesarias para el análisis.
  3. Haga clic en "Predecir Ahora!" para iniciar el análisis.
  4. El sistema procesará un registro de 10 segundos y 12 derivaciones.
  5. Los resultados mostrarán las probabilidades correspondientes a las diferentes clases diagnósticas.

Formato WFDB:

Si dispone de un registro WFDB (.mat y .hea), puede utilizar la opción de conversión disponible en la página principal para generar un archivo CSV multiderivación.

Desarrollado por JPDV y EMOG.
