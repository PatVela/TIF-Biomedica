Instrucciones de Uso

Siga estos pasos para utilizar el clasificador de ECG:

  1. Seleccione un archivo de datos de ECG en formato .csv. Asegúrese de que el archivo no exceda los 5 MB.
  2. Haga clic en "Predecir Ahora!" para iniciar el análisis.
  3. Los resultados se mostrarán en tablas detalladas.
  4. En caso de no tener archivo .csv, use la segunda opción de carga y el botón "Formatear ECG a CSV para convertir archivos .mat y .hba (subirlos al mismo tiempo)".

Información del Modelo
Arquitectura del Modelo

El modelo utiliza una Red Neuronal Convolucional (CNN) de tipo ResNet con 15 capas convolucionales, especializada para el análisis de series temporales de ECG.

Dataset de Entrenamiento

El modelo fue entrenado con el dataset encontrado en PhysioNet/Computing in Cardiology Challenge 2017.

  • Registros totales: 8,528
  • Derivación usada: MLII (o segunda derivación por defecto)
Métricas de Rendimiento (Ejemplo)

Las métricas aquí mostradas son representativas para este tipo de arquitectura y pueden variar.

  • Accuracy: ~96%
  • F1-score (promedio): ~0.82
